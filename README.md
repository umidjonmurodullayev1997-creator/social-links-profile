## 💡 What I Learned & Key Takeaways

Working on this project helped me solidify several core frontend concepts:

1. **Sass Nesting & Organization:** Structuring stylesheets cleanly using modern SCSS syntax and modular blocks.
2. **Full-Width Clickable Buttons:** Transforming `<a>` tags into `display: block` with `width: 100%` to ensure the entire container area is clickable, rather than just the text.
3. **Responsive Design Principles:** Adapting the layout smoothly across different screen sizes (Desktop and Mobile) using clean `@media` queries without code duplication.
4. **Design Accuracy:** Matching typography, spacing, and colors precisely according to the Figma design specs.
